# About This Project

This is a **full-featured admin dashboard** built as part of [The Odin Project](https://www.theodinproject.com/)'s Intermediate HTML and CSS curriculum. The project emphasizes modern layout techniques using **CSS Grid** as the primary tool for structuring a complex, multi-section interface.

## What is it?

A responsive admin dashboard UI featuring:
- **Sidebar navigation** with branding and menu items
- **Header section** with search bar, user profile, and action buttons
- **Main content area** displaying project cards, announcements, and trending items

## Learning Goals

This project reinforces key Grid concepts:
- Building complex layouts with nested grids
- Creating reusable grid containers within containers
- Structuring semantic HTML for a professional dashboard design
- Combining Grid with custom styling for a polished UI

## Key Features Built

- Sidebar with navigation and branding
- User info and action buttons
- Project cards grid
- Announcements section
- Trending items display
- SVG icons from [Material Design Icons](https://pictogrammers.com/library/mdi/)
- Custom font styling with Google Fonts

## Stack

- **HTML5** — semantic structure
- **CSS** — Grid layout, styling, and positioning
- **SVG icons** — scalable graphics
- **Google Fonts** — typography

## How to Use

1. Clone the repository
2. Open `index.html` in your browser
3. View the full dashboard layout in action
